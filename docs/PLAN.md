# 기획안 (v0.1) - 방송 검색형 아카이브

## 1. 목적
스트리머가 주 7회, 회당 최대 8시간 방송하고 다시보기는 한두 달 뒤 사라진다.
"이 얘기를 언제, 몇 분쯤 했더라?"를 **검색해서 찾는 것**이 핵심이다. 요약은 그 수단이다.

### 핵심 요구사항
1. 키워드·텍스트 검색 (필수)
2. 구간별 타임스탬프 (필수)
3. 용어집(닉네임·밈·인물·사담)을 저장해 이후 요약에 AI가 참고
4. 다시보기가 사라져도 요약·캡처는 영구 보관
5. 본인만 접근 (비공개)

## 2. 처리 파이프라인
```
다시보기 주소 → [GitHub Actions] 다운로드(저화질) → 음성/프레임 추출
 → 10분 조각 분할(병렬) → ① 전사본(시간 포함, 용어집 참고)
 → ② 구간 요약·키워드·신규 용어 후보 → 세션 단위 통합 요약
 → 구글 시트 기록 / 이미지 저장 / 원본 영상 삭제 → 사이트 자동 갱신
```
- 전사본을 저장하면 영상이 없어도 **용어집 보강 후 재요약**이 가능하다.
- 모르는 용어는 AI가 "후보"로만 뽑고, **사람이 확정한 것만** 용어집에 반영한다.

## 3. 데이터 모델 (구글 시트 탭)
| 탭 | 주요 컬럼 |
|---|---|
| vods | VOD ID, 주소, 방송 시작 일시, 길이, 세션 ID, 부(N부), 처리 상태 |
| sessions | 세션 ID, 날짜, 제목, 전체 요약, 대표 키워드, 라벨(정규/특별) |
| segments | 세션 ID, 부, 시작~끝, 유형(토크/게임), 게임명, 제목, 요약, 키워드, 확인 필요 여부, 캡처 경로 |
| glossary | 용어, 유형(닉네임/밈/인물/게임용어), 설명, 잘못 들리기 쉬운 표기, 상태(확정/후보) |

### 세션 묶기 규칙 (제안)
- 이전 VOD 종료와 다음 VOD 시작 간격 3시간 이내 → 같은 세션
- 하루 경계 새벽 6시
- 10분 미만 VOD는 기본 숨김
- 시트의 세션 ID를 직접 수정해 병합/분리 가능

## 4. 화면 구성 (모바일 우선)
```
검색 (홈)
 ├ 검색창 + 최근 방송 목록
 └ 검색 결과: 날짜 · 부 · 시각 · 구간 제목 · 요약 일부 · 키워드 하이라이트
방송 상세
 ├ 상단: 전체 요약, 키워드, 핵심 캡처
 ├ 타임라인 바 (토크/게임 색 구분)
 └ 블록(토크/게임) → 구간 카드 → 캡처 확대
키워드 모아보기 (2차)
용어집 보기 (2차, 관리는 구글 시트에서)
```
- 시각 표기: `2부 01:20:00 (오후 9:40경)`
- 구간 카드: 시각, 한 줄 제목, 요약 2~4문장, 키워드, 캡처 1~3장
- 불확실 표시된 구간에는 "확인 필요" 뱃지
- 원본 영상 링크는 없음 (만료)

## 5. 비용 추정 (가정 기반, 실측 전)
### 가정
- 방송 8시간 = 28,800초, 음성 입력 32토큰/초 → 약 92만 토큰
- 캡처 480장 × 258토큰 → 약 12만 토큰
- 사용 모델 단가(소개가 기간, ~2026-12-31): 입력 $0.75 / 출력 $3.75 per 1M 토큰
- 2027년 이후 표준가 적용 시 약 2배 가능성 (모델별 확인 필요)
- 출력 토큰은 현재 결과물 크기에서 추정한 값이며, 생각(thinking) 토큰은 미반영

### 방송 1건 추정
| 구조 | 소개가(~2026.12) | 2027 이후(2배 가정) |
|---|---|---|
| 현재 방식(1단계 요약+캡처 분석) | 약 $1~1.5 | 약 $2~3 |
| 전사본+요약 2단계(권장 구조) | 약 $2~3 | 약 $4~6 |

월 약 30건 기준: 1단계 약 $30~45 / 2단계 약 $60~90 (소개가 기준)

### 절감 방법
- 무음·잠수 구간 제거 후 전송 (음성 토큰은 시간에 비례)
- 게임 구간 캡처는 화면 전환 시점만
- 배치 방식(지연 허용 시 비용 절감 옵션) 검토

### 비용 외 한도
- GitHub Actions 비공개 저장소 월 2,000분: 현재 속도로는 방송 약 4~5건 분량 → 다운로드 고속화 필요
- 무료 Gemini 티어는 호출 한도 때문에 주 7회 처리 어려울 가능성
