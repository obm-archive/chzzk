# 확인 필요 항목 (체크리스트)

> 1차 요약 테스트(run-1, 방송 앞 30분) 결과를 바탕으로 정리. 우선순위: 🔴 높음 / 🟡 중간 / ⚪ 낮음
> 담당: **기획자** = 직접 확인 필요, **Claude** = 코드/실험으로 확인 가능

## A. 품질 검증

| 우선 | 항목 | 확인 방법 | 담당 | 상태 |
|---|---|---|---|---|
| 🔴 | 타임스탬프 정확도 | 원본 다시보기에서 05:14 부근("용인→청도 3시간 이야기"), 26:37 부근("새마을운동 발상지"), 약 28분대(터널 진입)가 맞는지 확인. 1분 이상 어긋나면 음성 조각 분할·시간 보정 필수 | 기획자 | ☐ |
| 🔴 | 요약 내용의 사실 여부 | 구간 요약 중 3~5개를 골라 실제 방송과 대조. 틀린 내용, 빠진 중요한 이야기 메모 | 기획자 | ☐ |
| 🔴 | 발화 주체 오인 | 시청자 채팅/도네이션 내용을 스트리머 발언으로 요약한 곳이 있는지 | 기획자 | ☐ |
| 🟡 | 닉네임·고유명사 표기 | `불확실한 부분`에 나온 항목이 실제 무엇인지 → 용어집 첫 항목 후보 | 기획자 | ☐ |
| 🟡 | 게임 구간 품질 | 토크가 아닌 **게임 구간** 30분도 같은 방식으로 테스트 (게임명 인식, 요약 품질) | Claude | ☐ |
| 🟡 | 용어집 반영 효과 | 용어집을 프롬프트에 넣었을 때 오해 요약이 줄어드는지 동일 구간으로 비교 | Claude | ☐ |
| ⚪ | 캡처 선정 방식 | 고정 60초 간격은 효과 낮음. 요약의 장면 시각 기준 캡처 + 화면전환 감지로 변경 후 비교 | Claude | ☐ |
